# ShopPluginMc

ShopPluginMc 1.0.20 recreation (in progress), customized to use Shards.

- Target: Paper 1.21.11+ / Java 21
- `/shop` category menu and `/shop <category>`
- Configured Shards category executes `/shardshop`
- `/mcshop reload` admin command
- Build validation via GitHub Actions

## Status
This repository currently contains an early menu scaffold, not a compatible release. The original ShopPluginMc catalog, buying/confirmation flow, quantity selection, product handling, editor, storage, and full configuration are not ported yet. Do not use this build on a production server.
